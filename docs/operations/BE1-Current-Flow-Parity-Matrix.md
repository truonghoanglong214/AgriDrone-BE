## Phase transition rule

Migration Phase 1 may start only from this matrix. A row moves from `PENDING_JAVA` to `PARITY_PROVEN` when its named Java replacement tests pass, its golden/API contract diff is reviewed, and no `LEGACY_GONE`, `BE2_KEEP` or raw-processing behavior has been copied into Java.
